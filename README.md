# Determination-of-the-Rydberg-Constant-from-Spectral-Data
A Python-based physics data analysis project that determines the Rydberg constant by using different fitting techniques like weighted linear regression to linearized hydrogen spectral data. The project demonstrates full error propagation, professional visualization with Matplotlib, and clear documentation of the scientific process.

## Repository Contents

- `data/spectral_measurements.csv`: The raw data used in the analysis.
- `notebooks/rydberg_analysis_clean.ipynb`: The final, polished analysis.
- `notebooks/rydberg_analysis_with_notes.ipynb`: The full analysis including my learning notes and explanations of the methods.
- `results/rydberg_plot.png`: The final plot showing the linearized data and fit.
- `README.md`: This file.
