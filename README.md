# Determination-of-the-Rydberg-Constant-from-Spectral-Data
A Python-based physics data analysis project that determines the Rydberg constant by using different fitting techniques like weighted linear regression to linearized hydrogen spectral data. The project demonstrates full error propagation, professional visualization with Matplotlib, and clear documentation of the scientific process.

## Repository Contents

- `Data`: This folder contains all the raw data used in the analysis.
- `Codes`: This folder contains all the Python codes used for analysis.
- `Results Plots`: This folder contains all the final plots from the data analysis.
- `Valen_Lebepe_Report.pdf`: This is the final report write up for this project, which explains the goal, the methodology and the theory behind all this.
- `README.md`: This file.
